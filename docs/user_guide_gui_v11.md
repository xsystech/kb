# Руководство пользователя XRM Director

## Обзор системы

**XRM Director** — система мониторинга и анализа журналов (логов) с поддержкой AI-агентов. Интерфейс разделён на два основных раздела:

- **LOG ANALYSIS** — инструменты для анализа журналов: источники, агенты, задания анализа, просмотрщик логов, ручной анализ.
- **DR PLAN** — управление инфраструктурой репликации: брокеры, группы, задания мониторинга, журналы.

Верхняя панель навигации содержит кнопку **О программе**, переключатель языка интерфейса и меню текущего пользователя.

---

## Источники журналов

Раздел **Источники журналов** позволяет настраивать подключения к источникам логов — серверам, файлам или другим системам, с которых агенты будут собирать данные.

![Источники журналов](/_media/01_sources.PNG)

### Элементы интерфейса

| Элемент | Описание |
|--------|----------|
| **Добавить** | Создать новый источник журналов |
| **Изменить** | Редактировать выбранный источник |
| **Удалить** | Удалить выбранный источник |
| **Параметры файлов** | Настройка параметров файловых источников |
| **Тест соединения** | Проверить доступность источника |

### Таблица источников

Таблица содержит следующие столбцы:

- **ID** — уникальный идентификатор источника
- **Имя** — название источника
- **Описание** — краткое описание
- **Адрес** — сетевой адрес или путь к файлу источника
- **Файлы** — количество связанных файлов
- **Статус** — текущее состояние соединения

### Добавление источника

1. Нажмите кнопку **Добавить**.
2. В открывшейся форме укажите имя, описание и адрес источника.
3. При необходимости настройте параметры файлов через кнопку **Параметры файлов**.
4. Нажмите **Тест соединения**, чтобы убедиться в доступности источника.
5. Сохраните источник.

## Агенты

Раздел **Агенты** предназначен для управления AI-агентами, которые анализируют поступающие журналы с использованием языковых моделей (LLM).

![Агенты](/_media/02_agents.PNG)

### Элементы интерфейса

| Элемент | Описание |
|--------|----------|
| **Добавить** | Создать нового агента |
| **Изменить** | Редактировать параметры выбранного агента |
| **Удалить** | Удалить выбранного агента |
| **Тест** | Запустить тестовый прогон агента |

### Таблица агентов

Таблица содержит следующие столбцы:

- **ID** — уникальный идентификатор агента
- **Имя** — название агента
- **Описание** — описание назначения агента
- **База знаний** — привязанная база знаний для анализа
- **Модель LLM** — используемая языковая модель
- **По у...** — параметр уведомлений или приоритета
- **Статус** — текущий статус агента (активен / неактивен)
- **Создан** — дата создания агента

### Добавление агента

1. Нажмите кнопку **Добавить**.
2. Задайте имя и описание агента.
3. Выберите базу знаний и языковую модель (LLM).
4. Настройте параметры уведомлений и статус.
5. Сохраните агента.
6. Для проверки работоспособности используйте кнопку **Тест**.

## Задания мониторинга

Раздел **Задания мониторинга** (DR PLAN → Задания) позволяет настраивать и запускать задачи непрерывного мониторинга источников данных.

![Задания мониторинга](/_media/03_jobs.png)

### Элементы интерфейса

| Элемент | Описание |
|--------|----------|
| **Добавить задание** | Создать новое задание мониторинга |
| **Удалить задание** | Удалить выбранное задание |
| **Запустить мониторинг** | Активировать выбранное задание |
| **Остановить мониторинг** | Приостановить выполнение задания |
| **Открыть просмотр логов** | Перейти к журналу событий задания |
| **🔄** | Обновить список заданий |

### Таблица заданий

Таблица содержит подробные метрики:

- **ID** — идентификатор задания
- **И...** — имя задания
- **А...** — агент, назначенный на задание
- **Режим** — режим работы задания
- **Статус** — текущий статус (запущено / остановлено)
- **Режим runt...** — режим runtime-выполнения
- **Глубина очереди** — текущая глубина очереди сообщений
- **Лаг** — отставание в обработке
- **Переи...** — количество переизданных сообщений
- **Пропу...** — пропущенные сообщения
- **Потер...** — потерянные сообщения
- **Жу...** — журнальные записи
- **Ерго...** — количество ошибок
- **Запущено** — дата и время последнего запуска

### Управление заданием

1. Нажмите **Добавить задание** и настройте параметры.
2. Выберите задание в таблице и нажмите **Запустить мониторинг**.
3. Для просмотра событий используйте **Открыть просмотр логов**.
4. При необходимости нажмите **Остановить мониторинг**.

## Log Viewer

Раздел **Log Viewer** предназначен для просмотра и анализа журналов в режиме реального времени или в режиме анализа исторических данных.

![Log Viewer](/_media/04_viewer.PNG)

### Режимы работы

| Режим | Описание |
|-------|----------|
| **Режим live-наблюдения** | Отображение поступающих событий в реальном времени |
| **Режим анализа истории** | Просмотр и анализ исторических данных выбранной сессии |

### Начало работы

1. В выпадающем списке **Сессия мониторинга** выберите нужную сессию.
2. Выберите режим viewer: **Режим live-наблюдения** или **Режим анализа истории**.
3. После выбора сессии отобразятся соответствующие данные журналов.

> **Примечание:** Если сессия не выбрана, система выведет сообщение «Выберите сессию для начала работы».

## Ручной анализ

Раздел **Ручной анализ** (Analysis) позволяет анализировать произвольный текст лога непосредственно в интерфейсе без привязки к активной сессии мониторинга.

![Ручной анализ](/_media/05_analysis.PNG)

### Элементы интерфейса

| Элемент | Описание |
|--------|----------|
| **Источник** | Выбор источника (по умолчанию — «Ручной ввод») |
| **Агент** | Выбор AI-агента для анализа текста |
| **Ввод** | Текстовое поле для вставки или ввода текста лога |
| **Очистить логи перед анализом** | Сбросить ранее полученные результаты перед запуском |
| **Анализировать** | Запустить анализ введённого текста |

### Порядок работы

1. В поле **Источник** выберите нужный источник или оставьте значение «Ручной ввод».
2. В поле **Агент** выберите AI-агента, который будет обрабатывать данные.
3. Вставьте или введите текст лога в поле **Ввод**.
4. При необходимости установите флажок **Очистить логи перед анализом**, чтобы удалить предыдущие результаты.
5. Нажмите кнопку **Анализировать**.
6. Дождитесь результатов анализа — они отобразятся на этой же странице.

В правом верхнем углу интерфейса расположены:

- **О программе** — информация о версии и лицензии системы.
- **Переключатель языка** — выбор языка интерфейса (по умолчанию: Russian).
- **Меню пользователя** (admin ▼) — управление учётной записью, выход из системы.

## Общие принципы работы с таблицами

Все таблицы в системе поддерживают единообразные элементы управления:

- **Фильтрация** — поля поиска под заголовком каждого столбца позволяют фильтровать записи по значению.
- **Сортировка** — нажатие на заголовок столбца переключает порядок сортировки (по возрастанию / убыванию), что обозначается стрелками ▲▼.
- **Пагинация** — в нижней части таблицы расположены кнопки «Пере» (первая страница), «Пред» (предыдущая), номер текущей страницы, «След» (следующая) и «Посл» (последняя).
- **Размер страницы** — выпадающий список «Размер страниц» позволяет выбрать количество строк на странице (10 и более).
- **Выбор строк** — чекбокс в левом столбце позволяет выбрать одну или несколько строк для последующего действия (изменить, удалить и т. д.).
